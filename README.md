# Chang Workshop Project Sharing

Supporting code, demos, and configuration files for projects featured on the Chang Workshop YouTube channel.

---

## 📁 Projects Overview

### 1. `MLXAudioSwift`
<ul>
  <li><b>Description:</b>b> A 100% on-device AI voice assistant demo built using Apple's MLX framework. It provides an end-to-end local pipeline incorporating Speech-to-Text (ASR), LLM inference, and streaming Text-to-Speech (TTS) accelerated via Metal GPU on Apple Silicon with a low memory footprint (~450MB–600MB).</li>li>
<li><b>Key Files:</b>b>
<ul>
  <li><code>MLXAudioSwift.xcodeproj</code>code> – Xcode project file.</li>li>
  <li><code>MLXAudioSwift/</code>code> – Source directory.</li>li>
  <li><b>Model Bundles:</b>b> Supporting model bundle structures for models such as <code>GLM-ASR-Nano</code>code>, <code>Soprano-80M</code>code>, <code>Gemma 3</code>code>, and <code>Qwen 2.5 (1.5B)</code>code>.</li>li>
</ul>ul>
</li>li>
</ul>ul>
